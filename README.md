# Customer Analytics & RFM Segmentation

An end-to-end customer analytics project using SQL Server, Python (Pandas and NumPy), and Power BI, based on the Online Retail II dataset.

## Project Overview

This project analyzes customer purchasing behaviour using Recency, Frequency, and Monetary (RFM) analysis. It includes customer segmentation, revenue analysis, geographic insights, and independent SQL business analysis.

## Tools & Technologies

- SQL Server – Data preparation and SQL analysis
- Python – Data processing using Pandas and NumPy
- Power BI – Interactive dashboards and reporting

## Key Analysis

- RFM-based customer segmentation
- Revenue contribution by customer segment
- Geographic customer and revenue analysis
- Repeat vs. one-time customer comparison
- Top 10 products by revenue

## Project Files

Project code, dashboard exports, and portfolio documentation are included in this repository. See the folders and files for details.

## Methodology Disclosure

The core RFM workflow was developed using a tutorial-guided learning approach and then recreated and customized. The Power BI dashboard was independently recreated and customized. Two additional SQL business analyses were developed independently.

**Note:** IKEA Gifting is the project case-study name. The analysis uses the Online Retail II dataset and is not based on actual IKEA data or affiliated with IKEA.
